Fuente: [Apuntes de Sistemas Operativos (ULL)](https://ull-esit-sistemas-operativos.github.io/ssoo-apuntes/introduccion/definiciones/)

## Temas

1. Introducción: Definiciones, tipos de sistemas, historia
2. Organización: Componentes, servicios, interfaz de programación, operación, estructura
3. Gestión de procesos: Procesos, planificación de la CPU, paso de mensajes, memoria compartida, hilos, sincronización
4. Gestión de la memoria: Memoria principal, paginación, memoria virtual
5. Gestión del almacenamiento: Almacenamiento secundario, sistemas de archivos, implementación
